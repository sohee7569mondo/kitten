# 거스르는 자리 — 주제 열둘로 갈라 쓰기

책에서 **본문(어긋나는 자리)과 맺음말 양쪽에** 나오는 표입니다.
지금은 문 여섯 개로만 갈려 있어서, 짝사랑으로 물으신 분이
「한순간도 혼자 두지 않는 관계」를 읽게 됩니다.

## 이 표가 문장으로 어떻게 조립되나

```
[거스르는 자리] + 가/이 + 오래 이어지면 + [닳는 것].
게을러서가 아니라 결을 거슬러 밀고 계셔서입니다.
```

보기 (연애운) —

> **한순간도 혼자 두지 않는 관계**가 오래 이어지면 **같은 사랑을 해도 마음이 남보다 빨리 닳습니다**.

그래서 **거스르는 자리는 명사구로 끝나야 합니다** — 「…자리」 「…사이」
「…시기」 「…생활」처럼요. 「…합니다」로 끝나면 문장이 깨집니다.

## 다섯 저울의 A·B 가 무슨 뜻인가

★ **A 는 사주가 A 쪽으로 기운 사람에게 힘든 상황**입니다. B 는 그 반대.

| 저울 | A 쪽 사람 | A 에 쓸 것 (A 쪽 사람이 힘든 자리) | B 에 쓸 것 |
|---|---|---|---|
| solo | 혼자 | 사람 속에서 계속 맞춰야 하는 | 아무와도 말 없이 혼자 있는 |
| form | 손에 잡히는 것 | 눈에 안 보이는 것만 다루는 | 마음은 안 보고 겉만 굴리는 |
| many | 하나 | 여러 개를 동시에 굴리는 | 하나만 몇 년씩 붙드는 |
| risk | 안정 | 판이 자주 뒤집히는 | 아무 일도 안 일어나는 |
| make | 정답 | 없던 답을 매번 만들어야 하는 | 정해진 대로만 따라야 하는 |

## 견본 둘 (제가 썼습니다)

```js
'짝사랑':{
  cost:'같은 마음을 품어도 남보다 빨리 지칩니다',
  solo:{ A:'그 사람 주변 사람들까지 계속 신경 써야 하는 사이',
         B:'아무에게도 말 못 하고 혼자만 알고 있는 사이' },
  form:{ A:'만나지는 못하고 글로만 오가는 사이',
         B:'마음 이야기는 없이 용건만 오가는 사이' },
  many:{ A:'이 사람 저 사람 동시에 재보게 되는 자리',
         B:'한 사람만 몇 년씩 바라보는 자리' },
  risk:{ A:'만날 때마다 온도가 달라지는 사이',
         B:'아무 일도 일어나지 않고 그대로인 사이' },
  make:{ A:'무슨 뜻인지 매번 혼자 해석해야 하는 사이',
         B:'정해진 인사만 주고받는 사이' }
},
'이별운':{
  cost:'같은 이별을 지나도 마음이 남보다 오래 걸립니다',
  solo:{ A:'혼자 있을 틈 없이 누군가 계속 곁에 있는 시기',
         B:'아무에게도 말하지 않고 혼자 삭이는 시기' },
  form:{ A:'정리할 물건도 자리도 없이 마음만 남은 시기',
         B:'짐만 정리하고 마음은 들여다보지 않는 시기' },
  many:{ A:'여러 사람을 만나며 잊으려 하는 시기',
         B:'그 한 사람만 몇 달씩 되새기는 시기' },
  risk:{ A:'연락이 왔다 끊겼다 하며 흔들리는 시기',
         B:'아무 변화 없이 같은 하루가 반복되는 시기' },
  make:{ A:'왜 끝났는지를 혼자 계속 해석해야 하는 시기',
         B:'남들이 하라는 대로만 정리하는 시기' }
},
```

**하는 일** : 주제마다 「결을 거스르면 어떤 자리인지」를 저울 다섯 개 ×
양쪽(A·B)씩, 모두 열 줄 씁니다. 그리고 「무엇이 닳는지」 한 줄을 씁니다.

**조립되는 문장** :
「[거스르는 자리]가 오래 이어지면 [닳는 것]. 게을러서가 아니라 결을 거슬러
밀고 계셔서입니다.」

**저울 다섯의 뜻** (A 는 그쪽으로 기운 사람에게 **힘든** 상황을 씁니다) :
- solo : A=사람 속에서 계속 맞춰야 하는 / B=아무와도 말 없이 혼자 있는
- form : A=눈에 안 보이는 것만 다루는 / B=마음은 안 보고 겉만 굴리는
- many : A=여러 개를 동시에 굴리는 / B=하나만 오래 붙드는
- risk : A=판이 자주 뒤집히는 / B=아무 일도 안 일어나는
- make : A=없던 답을 매번 만들어야 하는 / B=정해진 대로만 따라야 하는

1. 거스르는 자리는 **명사구로 끝냅니다** — 「…자리」 「…사이」 「…시기」
   「…생활」. 「…합니다」로 끝내지 마세요.
2. 15~30자. 짧고 구체적으로. 그 주제를 겪는 사람이 바로 떠올릴 장면으로.
3. **작은따옴표(')를 쓰지 마세요.** 인용은 「 」를 쓰세요.
4. **앰퍼샌드(&)를 쓰지 마세요.**
5. cost 는 「…습니다」로 끝나는 한 문장. 그 주제에서 무엇이 닳는지.
   (보기 : 연애운은 「같은 사랑을 해도 마음이 남보다 빨리 닳습니다」)
6. 존댓말, 나무라지 않는 말투. 「…하셔야 합니다」 같은 훈계 금지.
7. 아래 견본과 **똑같은 모양**으로만 답하세요. 설명 붙이지 마세요.
