# 건강운 — 항목마다 사주 어디로 갈리나 (벼리 설계 · 2026-09-13)

소희 님 설계(건강운-00-소희님설계.md)의 항목 하나하나에 **무엇으로
갈리는지**를 붙입니다. 이것이 책 조각을 만들 때의 표입니다.

## 앞판이 재미없었던 까닭

「토」가 ① · ③ · ⑥ 세 장에 다 나왔습니다. 가장 많은 오행 하나만 세 번
우려냈기 때문입니다. 사전질문 다섯도 한 장에 몰려서 설문 결과지처럼
읽혔습니다.

**그래서 새 판의 규칙 — 장마다 다른 재료를 씁니다.**

    ①  오행 다섯 + 십성 으뜸
    ②  화·수 + 십성 + 사전질문 where · rest
    ③  십성 식상·재성·관성 + 모으는/쓰는/지키는 몸
    ④  토·수 vs 목·화 + 사전질문 season
    ⑤  기운 다섯 단계 + 사전질문 rhythm          ★ 핵심
    ⑥  금·토 vs 목·화 + 십성 비겁·식상 + 기운
    ⑦  관성 + 거스르는 자리 + 사전질문 family
    ⑧  올해 세운(2026 병오 · 화)이 내 오행에 닿는 자리
    ⑨  후보 여섯에서 셋 뽑기
    ⑩  없음 — 아람 말상자

사전질문 다섯을 한 장에 몰지 않고 흩습니다 —
`where`·`rest` → ② · `season` → ④ · `rhythm` → ⑤ · `family` → ⑦

## ① 나는 어떤 몸을 타고났는가

    기본적인 체질의 결          오행 다섯 전부 (많은 순 · 없는 것은 뒤로)
                                ★ 오행마다 「{이름}님의 경우」 한 줄을 붙임
                                  3자리↑ 넉넉 / 2자리 보통 / 1자리 얇음 /
                                  0자리 한 자리도 없음
    몸이 강하게 쓰이는 부분      가장 많은 오행
    무리했을 때 먼저 나타나는    십성 으뜸 (비겁 / 식상 / 재성 / 관성 / 인성)
      생활 패턴                 ★ 오행이 아니라 십성 — 겹침을 피합니다
    몸을 편하게 유지하는 조건    기운 세기 (극신강~극신약)

## ② 나는 어떻게 쉬어야 회복되는가

    수면 리듬                    화가 넉넉 / 수가 넉넉 / 수가 비었을 때
    늦게 자는 것과 일찍 자는 것   화 넉넉 → 밤에 깨어 있는 쪽
                                금·수 넉넉 → 아침이 편한 쪽
    잠이 부족할 때 나타나는 패턴  사전질문 where (속 / 목·어깨)
    스트레스를 쉬는 방식          십성 (식상 말로 / 관성 참기 / 인성 혼자 생각 /
                                재성 일로 잊기 / 비겁 사람 만나기)
    혼자 쉬어야 하는지,          사전질문 rest ★ (푹 자기 / 움직여야 풀림)
      움직이며 풀어야 하는지
    회복에 필요한 생활 리듬       기운 세기

## ③ 나는 왜 살이 찌고, 빠지는가

    과식 패턴                    십성 식상 넉넉(입이 심심) /
                                재성 넉넉(바빠서 몰아서)
    간식과 식사 리듬             토 넉넉(조금씩 늘) / 토 얇음(끼니를 건너뜀)
    스트레스와 식습관             십성 관성 넉넉 (참다가 밤에)
    생활 리듬과 체중 관리         기운 세기
    살이 붙기 쉬운 생활 패턴      모으는 몸(토·수) / 쓰는 몸(목·화) /
                                정하면 지키는 몸(금) / 치우치지 않음
    빠진 뒤 다시 돌아가기 쉬운    기운 센 쪽(한 번에 끝내려 함) /
      패턴                      약한 쪽(굶다가 몰아서 먹음)

## ④ 나는 어떻게 먹어야 몸이 편한가

    식사 횟수 · 간격             토·수 넉넉 → 세 끼 규칙이 편함
                                목·화 넉넉 → 조금씩 자주가 편함
    아침을 먹는 방식             기운 약한 쪽 → 아침이 가장 중요
                                센 쪽 → 아침보다 저녁의 양
    과식과 폭식 패턴             오는 시간대로 좁힘 —
                                화 넉넉 → 밤 / 토 넉넉 → 오후
    간식과 야식                  화·수
    단백질·탄수화물·채소          일반 원칙 + 오행별 한 줄
                                ★ 특정 음식을 금지하지 않습니다
    (덧) 따뜻하게 / 시원하게      사전질문 season ★ (추위 / 더위)

## ⑤ 나는 어떤 다이어트가 맞는가          ★ 이 책의 핵심

    단기 집중형 vs 꾸준한 관리형  기운 세기 ★
                                센 쪽 → 덜어내는 방식 · 끝을 안 내는 것이 숙제
                                고른 쪽 → 같은 것을 오래 하는 방식
                                약한 쪽 → 채우면서 줄이는 방식 (순서가 반대)
    식사량 조절 · 식사 시간 관리   사전질문 rhythm ★
                                규칙적 → 틀을 정하는 방식 + 어긴 날의 규칙
                                몰아서 → 매일 하나만 + 힘 있는 날에 준비
    간헐적 식사 방식에 대한 성향   기운 약한 쪽에는 권하지 않습니다
                                토 넉넉하면 비교적 버팀
    스트레스성 먹기              십성 관성 · 식상
    요요를 만드는 나의 습관       기운 세기 (끝을 냄 / 굶다가 몰아서)

## ⑥ 나는 어떤 운동을 해야 하는가

    근력운동과 유산소             금·토 넉넉 → 근력이 잘 붙는 쪽
                                목·화 넉넉 → 움직이는 운동이 잘 맞는 쪽
    강도 높은 운동 vs 꾸준한 운동  기운 세기
    혼자 하는 운동 vs 함께하는     십성 비겁 넉넉 → 혼자 /
      운동                      식상 넉넉 → 같이 하면 오래 감
    운동을 시작하기 좋은 방식      기운 세기 (약한 쪽은 걷기부터)
    쉽게 포기하는 이유            십성 (재성 바빠서 / 관성 완벽하게 /
                                인성 준비만 / 식상 지겨워서 / 비겁 혼자라서)
    내 몸에 맞는 운동 습관        맺음 — 늘 붙임

## ⑦ 내 몸을 힘들게 하는 습관은 무엇인가

    수면 부족 · 불규칙한 생활     ②④ 와 겹치지 않게 — 여기서는
                                「알면서도 왜 못 고치나」만
    오래 참는 습관               십성 관성 ★
    스트레스를 쌓아두는 방식       사전질문 family ★ (기대는 / 짊어지는)
    과하게 몰아붙이는 습관        기운 센 쪽 · 십성 비겁
    쉬어야 할 때 쉬지 못하는 패턴  거스르는 자리 (AGAINST)
    맺음                        「지금 줄일 것 하나」 — 늘 붙임

## ⑧ 올해 내 몸은 무엇을 바꾸라고 하는가

★ 몇 월에 조심하라고 하지 않습니다. 계절 한 덩이로만 말하고, 끝은
  「바꿀 것 하나」로 맺습니다.

    올해 몸의 전체적인 흐름       2026 병오년 — 화 기운이 내 오행에 닿는 자리
                                화 넉넉 → 더 달아오름 · 식히고 자기
                                화 비었음 → 없던 기운이 들어옴 · 움직이기 좋은 해
                                수 넉넉 → 기복이 생김
                                토 넉넉 → 몸이 무거워지기 쉬움
                                금 넉넉 → 눌리는 느낌
    생활 리듬을 바꾸는 시기       계절 한 덩이
    무리하지 말아야 할 때         여름 한 덩이 (달을 늘어놓지 않음)
    새로운 습관을 만들기 좋은     계절 한 덩이
      흐름
    올해 가장 먼저 바꿔야 할     ⑨ 의 뽑기와 같은 규칙으로 하나만
      한 가지

## ⑨ 건강운에서 딱 세 가지만 기억하세요

★ 고정 세 가지가 아니라 **후보 여섯에서 셋을 뽑습니다.** 위쪽이 우선입니다.

    1  굶는 방식은 피하세요            기운 약한 쪽일 때
    2  잠을 먼저 되찾으세요            화 넉넉 · 또는 rest 「푹 자기」일 때
    3  참는 것을 줄이세요              관성 넉넉 · 또는 family 「짊어지는」일 때
    4  한 번에 바꾸려 하지 마세요      기운 센 쪽일 때
    5  남의 방법 말고 내 리듬으로      rhythm 「몰아서」일 때
    6  몸이 보내는 신호를 무시하지     늘 후보 — 셋이 안 차면 채웁니다
       마세요

## ⑩ 마지막으로 당신에게 건네는 말

갈리는 자리 없습니다. 아람의 말상자 하나로 끝냅니다.

## 지켜야 할 선 (모든 장)

- 병을 가리지 않습니다. 어느 장기가 아프다 · 무슨 병이 온다 — 안 씁니다.
- 사주로 읽는 것은 **생활 성향**뿐입니다.
- 방법은 누구에게나 맞는 일반 원칙으로. 굶기지 않고, 특정 음식을
  금지하지 않습니다.
- 「몸에 이상이 느껴지면 병원이 먼저」 — ③④⑤⑥ 에 한 줄씩 넣습니다.
