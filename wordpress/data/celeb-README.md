# 인물 사주 (/celeb/) — 넘겨드리는 상태

## 지금 어디까지 되어 있나

- `wordpress/pages/celeb.html` — 페이지 전체가 만들어져 있고 브라우저 검증까지 끝났습니다.
- 라이브(페이지 ID **193**)에는 네 블록 중 **두 개만** 올라가 있고 **비공개(draft)** 로 돌려두었습니다.
  남은 두 블록(풀이 엔진 · 인물 렌더러)은 한 번에 올리다 길이 제한에 걸렸습니다.
  반쪽짜리 페이지가 공개돼 있는 것보다 낫다고 보고 draft 로 내렸습니다.
- 로컬 파일은 완전합니다. 다음에 이어서 두 블록만 마저 올리면 바로 열립니다.

## 무엇을 하는 페이지인가

이름을 넣으면 그 사람의 사주를 세워 아홉 자리로 나눈 글을 보여줍니다.

    ① 공개 출생정보  ② 사주 구성  ③ 오행 분석  ④ 성향
    ⑤ 재능과 활동    ⑥ 재물의 흐름 ⑦ 대인관계  ⑧ 시기별 흐름  ⑨ 읽으실 때

글은 전부 계산에서 나옵니다. 지어낸 문장이 없습니다.
사진은 쓰지 않고 이름 · 직업 · 사주표만 씁니다.

## 지키고 있는 것

- 공개적으로 확인 가능한 생년월일만 씁니다.
- **생년월일이 확인되지 않으면 사주를 세우지 않습니다.** "출생정보 확인 중"으로만 둡니다.
  하루만 어긋나도 여덟 글자가 전부 달라지고, 틀린 날짜는 그 사람에게 실제 피해가 됩니다.
- 출생시간은 대개 알려져 있지 않습니다. 모르면 `hour: null` — 시주 없이 여섯 글자로만 봅니다.
  억지로 추정하지 않습니다.
- 모든 문장이 "명리학적으로는 …로 해석할 수 있습니다" 형태입니다.
- 연애 · 결혼 · 가족 · 건강 · 범죄 · 논란을 사주와 연결하지 않습니다.
- 재물 항목에 투자 판단 근거가 될 말을 넣지 않습니다.
- 맨 아래 고지문이 모든 인물 글에 똑같이 붙습니다.

## 검토 흐름

`celeb.html` 안의 `PEOPLE` 배열에서 `status` 를 바꾸면 됩니다.

    pending   이름으로 직접 찾았을 때만 보임 · "검토 대기" 표시
    approved  목록에 올라가고 누구나 볼 수 있음
    rejected  어디에도 나오지 않음

    { name:'유재석', role:'방송인', birth:'1972-08-14', hour:null,
      status:'approved', source:'어디서 확인했는지' }

## 제가 채우지 않은 것

**열두 분의 생년월일은 전부 비워 두었습니다.**
저는 지금 바깥 자료를 확인할 수 없어서, 기억에 의존해 실제 인물의 생년월일을 적으면
틀릴 수 있습니다. 위 원칙 그대로 — 확인되지 않은 날짜는 채우지 않았습니다.
공개된 자료에서 확인하신 뒤 `birth` 와 `source` 를 채워 주시면
그 자리에서 사주가 세워지고 아홉 자리 글이 나옵니다.
