   왜 백지였나
     저장된 글은 멀쩡했습니다. 워드프레스가 화면에 뿌릴 때
     wptexturize 라는 기능이 스크립트 안의 앰퍼샌드(&)를
     &#038; 로 바꿔버리는 것이 원인이었습니다.
     그 탓에   var t=(o&&o.topic)?...   한 줄이 문법 오류가 되고,
     책을 만드는 덩어리 전체가 통째로 멈춰 여섯 문이 모두 백지가 됩니다.

   이 스니펫이 하는 일
     1. 앰퍼샌드를 안 쓰는 문법으로 아홉 군데를 바꿉니다.
     2. 앞으로도 다시 안 깨지도록, 이 페이지에서만 wptexturize 를 뗍니다.

   붙여넣기
     1) WPCode → 새 스니펫 → 「Add Your Custom Code (New Snippet)」
     2) 종류(Code Type) 는 반드시  PHP Snippet
     3) 편집창 첫 줄에 이미 PHP 여는 태그가 한 줄 들어 있습니다.
        그건 그대로 두시고, 그 아래에 이 파일 내용을 통째로 붙여넣으세요.
     4) 저장 → 활성(Active) → 주소창에

          https://stellasaju.com/?stella_patch=amp160

     5) 표가 전부 초록으로 나오면 끝입니다. 그 다음 전자책을 열어보세요.

   중요
     이 스니펫은 지우지 말고 계속 활성으로 두세요.
     글을 바꾸는 부분은 ?stella_patch= 를 붙였을 때만 동작하고,
     평소에는 페이지 160 을 wptexturize 로부터 지켜주기만 합니다.

   되돌리기
     혹시 문제가 생기면   ?stella_patch=amp160_undo
   ════════════════════════════════════════════════════════════ */

add_action( 'wp', function () {
	if ( is_page( STELLA_AMP_PAGE ) ) {
		remove_filter( 'the_content', 'wptexturize' );
	}
} );

		'<p>화면에 뿌렸을 때 script 안에 깨진 앰퍼샌드 : <b style="color:%s">%d개</b> %s</p>',
		0 === $ent ? '#7bff9b' : '#ff7b7b',

		0 === $ent ? '(0 이어야 정상입니다)' : ''
	);

	exit;
} );
