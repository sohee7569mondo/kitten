`[stella portone hook] … 결제를 확인하지 못했어요.` 가 8월 30일과 31일에

V1 시크릿을 V2 자리에 넣음 / 채널과 시크릿이 안 맞음(테스트 대 실연동) /

## 스니펫을 만들 때 지킬 것

- `.WPCODE.txt` 에 PHP 여는 태그가 **하나도** 없어야 합니다. 한글 주석 안에
  써도 사고가 납니다. 항상 확인 —
  `{ echo '<?php'; cat f; } > /tmp/x.php && php -l /tmp/x.php` 그리고 여는 태그 개수 세기.
- 페이지 160 은 줄바꿈이 섞여 있습니다(CRLF 166곳, LF 약 11,500곳).
  반드시 **바이트 그대로** 다루세요. 파이썬 text 모드는 CRLF 를 조용히 바꿉니다.
- 고치는 스니펫은 **미리보기부터** 만듭니다.
  `?stella_patch=X` 는 보여주기만, `&go=1` 로 적용, `&undo=1` 로 되돌리기.
- 관리자 전용 도구가 **말없이 홈으로 보내면 안 됩니다.** 왜 거절했는지
  화면에 적어야 합니다. 오늘 그것 때문에 원인을 좁히는 데 몇 시간이 걸렸습니다.
