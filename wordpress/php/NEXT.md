### 이 과정에서 알게 된 것 두 가지

**REST 는 nonce 없이는 로그인을 안 잡습니다.** 브라우저에서
`/wp-json/stella/v1/me` 를 그냥 부르면 로그인 상태여도 `member:false` 가
옵니다. 그래서 `wp_head` 에 `window.STELLA_NONCE` 를 심는 스니펫
(「스텔라 로그인 열쇠」)을 만들고, 부를 때 `X-WP-Nonce` 를 같이 보냅니다.
서버 안에서 확인할 때는 `rest_do_request()` 를 쓰면 nonce 가 필요 없습니다
— 이게 `?stella_me=1` 점검판이 하는 방식입니다.

**⚠ 스니펫 416 「Snippet login nonce」의 원본이 사라졌습니다.** 진단 코드를
「718 을 열어 전부 지우고」로 여러 번 반복해 드리다가 사용자가 416 을 열어
덮어썼습니다. 사본이 없습니다. 이름으로 미루어 위의 nonce 일을 하던 것으로
보이고, 그 기능은 「스텔라 로그인 열쇠」로 대신 만들었습니다.
**앞으로 진단 코드는 매번 새 스니펫으로 만들고, 기존 스니펫을 덮어쓰라고
하지 말 것.**
