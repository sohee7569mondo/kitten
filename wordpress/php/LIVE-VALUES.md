# 사이트에 실제로 들어가 있는 값

`wordpress/php/stella-signup.php` 는 **오래된 사본입니다.** 값이 사이트와
여러 군데 어긋나 있으니 값을 판단할 때 이 파일을 믿지 마세요.

확인하는 법 — 관리자로 로그인한 채 아래를 엽니다.

    https://stellasaju.com/?stella_check=1

## 2026-08-31 확인한 값

| 이름 | 저장소 사본 | **실제 사이트** |
|---|---|---|
| `STELLA_TRIAL` | true | **false** (실결제) |
| `STELLA_ORB_KRW` | — | **990** |
| `STELLA_PRICE_BASE` | 5 | **1** (풀이 한 편 990원) |
| `STELLA_PRICE_FULL` | 50 | **25** (인생길잡이 24,750원) |
| `STELLA_PRICE_ONELINE` | 5 | **0** |
| `STELLA_PRICE_DEEP` | 5 | **0** |
| `STELLA_WELCOME_ORBS` | 5 | **1** |
| `STELLA_EVENT_ORBS` | 15 | **1** |

가입하면 구슬 **2개**를 받습니다 (축하 1 + 오픈 기념 1).

## 한 줄 질문과 심화 질문이 0인 것은 의도입니다

실수가 아닙니다. 파는 단위를 「풀이 한 편」 하나로 두고, 질문은 값을
따로 매기지 않고 안에 전부 넣어 해설을 두껍게 하려는 것입니다.
0 을 보고 버그로 오해하지 마세요.

## 인생길잡이가 0원으로 보이는 것도 값 문제가 아닙니다

「STELLA - 결제 상태 점검」(스니펫 266) 107번째 줄과
「STELLA - 포트원 백엔드」(스니펫 265) 669번째 줄이
`stella_po_bundle_krw('guide')` 를 값으로 찍는데,
그 함수는 예전 「묶음 특별가」 장치이고 지금은 **일부러 0 을 돌려줍니다**
(스니펫 265 의 64번째 줄에 그렇게 적혀 있습니다).

진짜 값은 `stella_price() × STELLA_ORB_KRW` 로 셈합니다.
25구슬 × 990 = **24,750원** 이 맞습니다.

점검창 두 줄은 아직 안 고쳤습니다. 고칠 때 이 문서도 같이 지워주세요.

## 결제창을 보려면

구슬이 남아 있으면 풀이 한 편(1구슬)은 그냥 열려서 결제창이 안 뜹니다.
잔액보다 비싼 것을 골라야 뜹니다 — **나의 인생길잡이(25구슬)** 를 쓰세요.

## 스크립트 안에 앰퍼샌드를 쓰지 마세요

워드프레스의 `wptexturize` 가 페이지 본문 `<script>` 안의 맨 앰퍼샌드를
`&#038;` 로 바꿉니다. `&&` 하나가 페이지의 스크립트 덩어리를 통째로
죽입니다. 페이지 137 과 160 이 이것 때문에 백지가 됐습니다.
`if` 를 겹쳐 쓰거나 삼항 연산자를 쓰고, 문자로 필요하면 `\x26` 을 쓰세요.
페이지 160 은 `patch160` 스니펫이 `wptexturize` 를 떼어 막아두고 있습니다.
