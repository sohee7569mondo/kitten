## 주제를 갈라내는 자리를 한 곳으로 (2026-09-08 적어둠)

합쳐서 **마흔두 군데**입니다. 그것도 **여섯 가지 서로 다른 방식**으로

    LENS_TOPIC         16   63 7153 7181

    __ct            10121 10131 10337 10405 10503 12105~12111
    topicAllowed     9229 11789 12042 12354 12358
    loveTopicOf      9236 9319

### 왜 고쳐야 하나

주제 하나를 새로 더할 때마다 여섯 군데를 다 고쳐야 합니다.
하나라도 빠뜨리면 그 주제만 글이 안 나오거나, 반대로 엉뚱한
주제에 남의 글이 나옵니다.

실제로 겪은 것 —
* 「연애 문에만 걸려 있던 빗장」 — 주제별 글이 door-love 일 때만
  보이게 되어 있었습니다 (patch160 주석 12351 줄).
* patch160_gap 의 열한 번째 자리가 AXIS_WARM_TOPIC 을 붙잡고
  있었는데 그 자리가 안 걸려서, 다 되는 열 자리까지 통째로
  막혔습니다. gap2 를 따로 만들어야 했습니다.

### 어떻게 고치나

표 하나로 모읍니다. 문 slug 와 주제를 받아서 「이 꼭지를 낼지」
한 군데서만 답하게 합니다.

    var TOPIC_MAP = {
      'door-love':   { '연애운':[...], '결혼운':[...], ... },
      'door-career': { ... },
      ...
    };
    function shows(slug, topic, key){ ... }

여섯 방식을 한꺼번에 걷어내지 말고, 새 표를 먼저 놓고 한 방식씩
옮기는 것이 안전합니다. 옮길 때마다 견본 책 여섯을 다시 뽑아
글이 그대로 나오는지 봐야 합니다.

### 지금 손대지 않는 이유

돌아가고 있습니다. v1 은 「전체를 한 번 완성」이 먼저입니다.
