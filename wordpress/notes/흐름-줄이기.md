소희 님 :
> 「홈에서 연애운 눌러, 정보 입력하고 운세보기를 눌러, 그럼 벼리가 나오고
>   시작할게요가 떠, 그다음 질문이 있고, 다음 카드 3장을 골라,
>   벼리에게 물어보기 누르면 기본풀이가 나와, 그다음 내 전자책 펼쳐보기가 나와
>   .............. 너무 길어」

## 지금 — 다섯 화면 · 네 번 누름

| | 화면 | 하는 일 |
|---|---|---|
| 1 | 홈 | 문 고르기 |

| 5 | reading-book 160 | 책 |

## 156 은 책과 같은 말을 두 번 합니다

156 이 보여주는 것 :

```
01 태어난 시각을 바로잡습니다   (진태양시)
02 사주 원국 — 네 개의 기둥
03 타고난 기운의 비율
04 십 년마다 바뀌는 판 — 대운
05 태어나던 밤의 하늘
06 접수 내역
```

책(160)이 보여주는 것 :

```
근거 하나  …
근거 둘    …
근거 셋    기운의 저울   ← 오행. 03 과 같은 것
…          여덟 글자     ← 02 와 같은 것
…          대운          ← 04 와 같은 것
```

**같은 계산을 두 번 보여주고 있었습니다.**
게다가 156 은 무엇을 저장하지도, 만들지도 않습니다 — 코드를 읽어보니
브라우저에 이미 있는 값을 읽어 화면에 그리기만 합니다. 건너뛰어도
책이 만들어지는 데 아무 문제가 없습니다.

**156 을 없애지 않습니다.** 흐름에서만 빼고, 책 안에
「이 값이 어떻게 나왔는지 자세히 보기」 한 줄로 남깁니다.
믿음을 주려고 만든 쪽이니 없애면 안 되고, 길목을 막고 있을 이유도 없습니다.

## 137 도 더 줄일 수 있습니다

- 벼리 인사 네 줄은 오늘 이미 접었습니다 (`patch137_talk`)

  한 화면에서 이어지게 하면 「또 눌러야 하나」가 사라집니다.
