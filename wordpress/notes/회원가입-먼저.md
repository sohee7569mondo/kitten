# 회원가입을 먼저 · 아이디와 비밀번호로 — 2026-09-09

소희 님 :
> 「회원가입을 먼저 하는 걸로 하자. 아이디 패스워드 없으니까 운세 볼 때 힘들어.
>   모바일에서 보니까 메일 링크 보내주네」

## 무엇이 문제였나 (코드에서 확인한 것)

### 1) 문에서 가입하면 비밀번호가 아무거나 만들어집니다

`stella-signup` 안 :

```php
$pass = wp_generate_password( 16, true, false );
$uid  = wp_insert_user( array( ..., 'user_pass' => $pass, ... ) );
```

계정은 만들어지는데 **손님은 자기 비밀번호를 모릅니다.**
그러니 다시 들어올 길이 메일 링크뿐입니다.

### 2) 메일 링크는 휴대폰에서 특히 잘 샙니다

- 메일 앱이 링크를 미리 열어봅니다 → 그 순간 열쇠가 쓰여 없어짐
- 메일함을 왔다갔다 해야 함 → 여기서 많이 나갑니다
- 관리자·편집자 계정은 아예 막혀 있음 (일부러 그렇게 둔 것)

### 3) 그런데 `/signin/` 은 이미 다 돼 있습니다

`stella_pw` 가 만든 쪽입니다.

```
/signin/           이메일 + 비밀번호로 들어오기
/signin/?join=1    가입하기
/signin/?next=...  들어온 뒤 갈 곳
```

**새로 만들 것이 거의 없습니다.** 문 폼과 이어 붙이기만 하면 됩니다.

## 어떻게 바꾸나

### 화면을 늘리지 않습니다

가입 화면을 앞에 하나 더 놓으면 걸음이 늘어납니다.
소희 님이 「너무 길어」 하신 것과 정면으로 부딪혀요.

그래서 **문 폼 안에서 가입이 끝나게** 합니다.
문 폼은 이미 이름 · 이메일 · 휴대폰 · 동의를 받고 있습니다.
여기에 **비밀번호 한 칸**만 더 놓으면 그 자리에서 계정이 생깁니다.

```
걸음 3  성 · 이름 · 이메일 · 휴대폰 · 동의
                              ↓
걸음 3  성 · 이름 · 이메일 · 비밀번호 · 휴대폰 · 동의
        ────────────────────────────
        「운세 보기」를 누르면 계정이 만들어집니다.
        다음부터는 이메일과 비밀번호로 바로 들어오세요.
```

**걸음이 하나도 안 늘어납니다.** 지금 누르던 그 단추 그대로입니다.

### 손댈 곳 셋

| | 무엇 | 크기 |
|---|---|---|
| 1 | `/signup` 이 받은 비밀번호를 쓰게 (지금은 아무거나 만듦) | 작음 |
| 2 | 문 폼에 비밀번호 칸 하나 + 보낼 때 같이 실어 보내기 | 중간 |
| 3 | 가입 끝난 뒤 「이메일과 비밀번호로 다음에 바로 들어오세요」 한 줄 | 작음 |

### 규칙

- 여덟 자 이상. 그 이상 까다롭게 굴지 않습니다 — 까다로울수록 나갑니다
- 비밀번호를 안 적으면 지금처럼 메일 링크로 갑니다 (막지 않습니다)
- 이미 있는 이메일이면 「이미 가입되어 있어요. 비밀번호로 들어오시겠어요?」
  하고 `/signin/` 으로 보냅니다 (지금은 409 로 막히기만 합니다)
- 메일 링크는 **없애지 않습니다.** 비밀번호를 잊었을 때 쓸 길로 남깁니다

## 재는 자

바꾸기 전후로 **문 폼을 제출한 사람 중 몇 명이 책까지 갔는지**를 봅니다.
지금은 메일함을 다녀와야 해서 여기서 제일 많이 샙니다.
