# patch_freetext — 쪽에 박힌 「구슬 3개, 3,000원」 지우기 (2026-09-27)

## 왜 필요한가

`?stella_freeall=free` 가 문 다섯의 `var TRIAL` 을 true 로 바꿔 값을 안 받게
했습니다. 그런데 두 쪽이 아직 옛말을 합니다.

  마이페이지(185)   「문 하나를 여는 데 구슬 3개, 3,000원을 씁니다.」  두 곳
  자료 쪽(156)      「쓰는 구슬 · 없음」

★★ 제가 「조각 patch_open 을 꺼 주세요」라고 말씀드린 것은 **틀렸습니다.**
  patch_open 은 `wp_head` 로 화면에 얹는 조각이 아니라
  `?stella_open=apply` 로 **쪽 글을 한 번 고치고 끝나는** 조각입니다.
  이미 고쳐 놓았으니 꺼도 글은 그대로 남습니다.

☞ 조각을 볼 때 **얹는 조각인지 고치고 끝나는 조각인지** 먼저 가립니다.
  얹는 조각은 끄면 사라지고, 고치는 조각은 꺼도 안 사라집니다.

## 어긋나 있던 상태

마이페이지는 블록이 둘입니다.

  첫 블록   쪽에 박힌 글을 그대로 보여줍니다      → 「3,000원」
  둘째 블록 서버(`/wp-json/stella/v1/me`)가 다시 씁니다
            `me.trial ? '지금은 체험판이라 모든 문이 무료입니다…' : …`

그래서 **회원으로 보면 무료, 손님으로 보면 3,000원**이었습니다.
가입 안 한 손님에게만 값을 말하고 있었던 셈입니다.

## 지키는 것

  · 정규식 0 — `strpos` 와 `str_replace` 만 (10만자 줄에서 504 를 낸 적이 있음)
  · `wp_slash()` 로 감싸 저장하고, 저장 뒤 역빗금을 다시 세어 어긋나면 되돌림
  · 백업을 따로 두지 않고 찾을 글과 넣을 글을 **맞바꾸기만** 함
    → 그 사이에 다른 조각이 넣은 글을 건드릴 일이 없음 (undo 가 위험한 까닭을 피함)
  · 쪽 두 개만 봄. 스니펫을 훑지 않음
