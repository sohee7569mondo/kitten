# 스텔라 랩 — 어떻게 만들지 (2026-09-08 소희 님이 정하심)

## 두 층이 서로 다릅니다

    목록(홈)   →  예전 것이 낫다
    테스트 안  →  오늘 만든 것이 낫다

목록은 **고르는 곳**이라 한눈에 훑기 좋아야 하고,
테스트 안은 **한 문항씩 머무는 곳**이라 손맛이 있어야 합니다.

## 목록 — 예전 「오늘은 뭘 해볼까」 꼴

    · 맨 위 큰 인사 — 「오늘은 뭘 해볼까」
    · 「가입도 앱도 없어요. 한 개에 일이분이면 끝나고, 전부 공짜입니다.」
    · 「오늘의 검사」 큰 카드 한 장
    · 테스트 찾기 (검색창)
    · 갈래 딱지 — 전체 · 성격 · 마음 · 연애 (+ 돈 을 더할 것)
    · 카드마다 다른 파스텔 색, 갈래 딱지 · 제목 · 한 줄 ·
      「12문항 · 2분」 · ＋ 단추

## 테스트 안 — 오늘 만든 꼴

    · 맨 위에 **지금 어디쯤인지** 표시 (점과 채워지는 줄, 움직이는 아이콘)
    · 문항마다 STEP 딱지 — 「STEP 3 · 예산」처럼 어디쯤인지 한 번 더
    · 선택지마다 **이모지 타일** (또는 작은 그림)
    · 고르면 잠깐 표시가 남고 다음으로 넘어감
    · 「← 이전」으로 돌아갈 수 있음
    · 결과는 영수증/티켓 꼴 — 유형 · 한 방 문장 · 설명 ·
      「나와 정반대 유형」
    · 공유하기 — 카카오톡 · X · 링크 복사 · 다른 앱
    · 그 아래 **유앤미로 가는 자리** (next-uandme.block.html)

## 갈 길

    랩 테스트  →  유앤미 궁합  →  스텔라사주

가벼운 것에서 시작해 둘이 보는 것으로, 거기서 자기 것으로.

## 아직 못 정한 것

* **엔진을 스니펫 하나로 뺄지** — 지금은 테스트마다 21KB 짜리
  한 덩어리라, 한 군데 고치려면 여섯 쪽을 다 고쳐야 합니다.
  엔진을 빼면 새 테스트가 문제 꾸러미 3KB 로 끝납니다.
  첫 개를 만들어 보고 정하기로 했습니다.

  둘밖에 없어서, 지금 돌리면 어떤 날은 근사하고 어떤 날은 허전합니다.
  **도쿄를 맨 위에 고정합니다** — 사진 32장이 있어 제일 예쁩니다.
