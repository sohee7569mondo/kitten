## 며칠을 헤맨 진짜 까닭 — 구조

띠를 **자바스크립트가 만들어 끼워넣었습니다.**

    조각이 켜짐 → 화면이 다 그려짐 → JS 가 띠를 만듦 →
    자리를 찾아 끼움 → 여백을 인라인으로 놓음

이 사슬에서 한 군데만 어긋나면 여백이 안 먹습니다. 그리고 **제가 확인할
방법이 없었습니다** — 제 사본(home-v16.html)과 살아 있는 홈의 구조가
달라서 그려봐야 소용이 없었습니다. 제 사본에는 띠 아래에
「스텔라사주보기」 제목 줄이 있는데 살아 있는 쪽에는 없습니다.

☞ **모양 이야기는 반드시 살아 있는 쪽을 받아서 그립니다.**
  `wordpress/pages/home-62.live.html` 에 받아 두었습니다.

## 바꾼 구조

    전   JS 가 만들어 끼움 · 자리는 실행할 때 찾음 · 여백은 인라인
    후   쪽 글에 HTML 로 박음 · 자리 고정 · 여백은 CSS 한 줄

    <section class="sh-section" id="hp-open">
      <div class="wrap">
        <div id="hp-band"> … </div>
      </div>
    </section>

`.wrap` 안에 있으니 좌우가 저절로 다른 줄과 같아집니다.
여백은 이 한 줄이 정합니다 —

    #stellar-home #hp-open{ padding:64px 0 120px; }
    @media(max-width:700px){ … padding:44px 0 84px; }

## 조각 patch_homeband

    살펴보기  ?stella_homeband=1
    넣기      ?stella_homeband=apply
    빼기      ?stella_homeband=undo

★ 넣을 글 앞뒤에 표지말을 둡니다 — `<!-- STELLA-BAND-START -->` 와 END.
  처음에는 「주석부터 첫 `</section>` 까지」로 지웠더니 **675자를 더
  지웠습니다.** 표지말로 잡으니 되돌린 것이 원본과 **글자 하나까지** 같습니다.
