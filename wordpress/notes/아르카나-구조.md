# 아르카나(스텔라타로) 구조안 — 2026-09-09 (다시 씀)

## 먼저 — 제가 잘못 짚었던 것

처음에 「책(160)의 세 장 묶어 읽기가 아르카나에 안 걸린다」고 봤습니다.
**틀렸습니다.** 아르카나 문(172)을 통째로 읽어보니 완전히 딴 물건입니다.

| | 다섯 문 | 아르카나 |
|---|---|---|
| 생년월일시 | 받음 | **안 받음** |
| 회원가입 · 결제 | 있음 | **없음 · 하루 다섯 번 무료** |
| 결과 | 전자책 한 권 | **그 자리에서 바로** |
| 책(160) | 씀 | **안 씀** |

그러니 `DOOR_TOPICS` 를 고쳐도 아르카나는 아무 변화가 없습니다.
(`patch_tarot2` 는 쓰지 않습니다.)

## 지금 아르카나가 하는 일

```
STEP 1  질문 하나        — 40자, 안 적어도 됨
STEP 2  세 장 고르기      — 78장을 섞어 20장을 펼침
STEP 3  카드가 하는 말    — 낱장 셋
          I   지금
          II  넘어야 할 것
          III 그 너머
```

**빠진 것 둘**
1. 주제를 안 묻습니다 → 78장 전부에서 아무거나 나옵니다
2. 세 장을 **묶어** 읽는 말이 없습니다 → 낱장 셋으로 끝납니다

소희 님이 하신 말 그대로입니다 —
「세 장 그림 설명만 있어」 · 「주제를 묻기로 했잖아, 그래야 해당 카드를 뽑지」

## 바꿀 그림

```
STEP 1  무엇에 대해              ← 새로
          연애 · 결혼 · 재물 · 일 · 마음고생 · 오늘의 선택
STEP 2  질문 하나                (지금 것 그대로, 선택)
STEP 3  세 장 고르기              ← 그 주제의 패에서만 섞습니다
STEP 4  카드가 하는 말
          낱장 셋
          + 잇는 한 줄            ← 새로 · 주제마다
          + 셋을 겹쳐 놓으면      ← 새로 · 이게 「세 장에 대한 설명」
```

### 주제마다 패가 다릅니다

카드는 원래 네 갈래로 나뉩니다. 아르카나 카드에도 이미 그렇게 들어 있어요.

| 갈래 | 무엇을 다루나 | 장수 |
|---|---|---|
| 메이저 | 큰 흐름 · 운명 | 22 |
| 컵 (Heart) | 마음 · 관계 | 14 |
| 완드 (Flame) | 의욕 · 일 | 14 |
| 소드 (Thought) | 생각 · 갈등 | 14 |
| 펜타클 (Earth) | 돈 · 현실 | 14 |

| 주제 | 섞는 패 |
|---|---|
| 연애 | 메이저 + 컵 |
| 결혼 | 메이저 + 컵 + 펜타클 |
| 재물 | 메이저 + 펜타클 |
| 일 | 메이저 + 완드 + 펜타클 |
| 마음고생 | 메이저 + 소드 + 컵 |
| 오늘의 선택 | 일흔여덟 장 전부 |

이러면 「연애를 물었는데 돈 카드가 나오는」 일이 없어집니다.
그리고 **거짓말이 아닙니다** — 정말로 그 갈래만 섞습니다.

### 셋을 겹쳐 놓으면 (세 장에 대한 설명)

조합이 너무 많아 하나하나 쓸 수 없습니다. 그래서 세 잣대로만 읽습니다.
이건 책에서 이미 쓰고 있는 방식이라 손님이 낯설어하지 않습니다.

| 잣대 | 보는 것 | 갈래 |
|---|---|---|
| 큰 카드 수 | 메이저가 몇 장 | 0 · 1 · 여럿 |
| 흐름 | 세 장의 숫자가 오르나 내리나 | 오름 · 내림 · 평평 |
| 뒤집힘 | 거꾸로 나온 것이 몇 장 | 0 · 일부 · 셋 |

세 잣대 × 세 갈래 = 아홉 덩어리.
