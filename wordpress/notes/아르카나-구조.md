## 지금 무엇이 빠져 있나 (찾은 것)

책(160) 안에 **세 장을 묶어 읽는 표**가 이미 있습니다.

```js
var COMBO_TOPIC = { '결혼운':{…}, '연애운':{…}, '재회운':{…}, '이별운':{…}, '짝사랑':{…} };

function comboSay(key, n){
  if(slug !== 'door-love'){ return ''; }   // ← 빗장
  …
}
```

표는 세 가지 잣대로 읽습니다.

| 잣대 | 무엇을 보나 | 갈래 |
|---|---|---|
| 큰 카드 수 | 메이저가 몇 장인가 | 0장 · 1장 · 여러 장 |
| 숫자 흐름 | 세 장의 숫자가 오르나 내리나 | 오름 · 내림 · 평평 |
| 뒤집힘 | 몇 장이 거꾸로 나왔나 | 0장 · 일부 · 3장 |

주제 하나에 아홉 덩어리입니다. **그런데 빗장이 `door-love` 하나로 잠겨 있어
아르카나 문은 이 표를 아예 안 탑니다.** 그래서 카드 낱장 뜻만 나옵니다.

## 고칠 것 셋

### 1) 빗장 풀기
`slug !== 'door-love'` 를 「표에 그 주제가 있으면 누구든 쓴다」로 바꿉니다.
문 이름이 아니라 **주제 이름**으로 걸어야 맞습니다 — 결혼운은
벼리로 물으나 아르카나로 물으나 결혼운이니까요.

### 2) 아르카나 주제를 다른 문과 같은 이름으로
같은 이름을 쓰면 이미 있는 표가 그대로 걸립니다. 새로 안 써도 됩니다.

| 자리 | 주제 | 표가 있나 |
|---|---|---|
| 1 | 연애운 | **있음** — 바로 나옵니다 |
| 2 | 결혼운 | **있음** |
| 3 | 재회운 | **있음** |
| 4 | 재물운 | 없음 — 새로 씁니다 |
| 5 | 직업운 | 없음 — 새로 씁니다 |
| 6 | 오늘의 선택 | 없음 — 타로만의 자리 |

### 3) 주제마다 패가 달라지게
이미 `patch_tarot_topics` 에서 씨앗에 주제를 더해두었습니다.
주제 이름을 바꾸면 씨앗도 같이 바뀌므로 **주제마다 다른 열 장**이 나옵니다.
