# 카카오톡에 「스텔라 랩」 앱을 따로 만들기 — 2026-09-09

소희 님 : 「지금 궁합용 유앤미만 만들었는데 스텔라랩을 따로 만들어야
아래에 로고가 나갈듯」

**맞습니다.** 공유 카드 맨 아래 「♥ 유앤미」는 카카오 개발자 화면에
적어 둔 **앱 이름**입니다. 코드로는 절대 못 바꿉니다. 앱을 새로
만드는 수밖에 없습니다.

## 어디를 누르시면 되나

1. developers.kakao.com 로그인
2. 왼쪽 위 **내 애플리케이션** → **애플리케이션 추가하기**
3. 세 칸을 채웁니다

   | 칸 | 넣을 말 |
   |---|---|
   | 앱 이름 | `스텔라 랩` |
   | 사업자명 | `스텔라 사주` |
   | 카테고리 | 취미·엔터테인먼트 |

4. 만들어진 앱을 눌러 들어가서 **앱 설정 → 플랫폼 → Web 플랫폼 등록**

   ```
   https://stellasaju.com
   ```

5. **앱 설정 → 앱 키** 에서 **JavaScript 키**를 복사해 저에게 주세요.
   (32글자짜리 영어·숫자 뭉치입니다)

6. **제품 설정 → 카카오 로그인**은 켜지 않으셔도 됩니다.
   공유만 쓰니까요.

## 그림(앱 아이콘)

앱 아이콘이 카드 아래 동그라미로 나갑니다.
**정사각형 · 500×500** 한 장이면 됩니다. 만드시면 같은 화면
**앱 설정 → 일반 → 앱 아이콘**에 올리시면 됩니다.

## 그 다음은 제가 합니다

키를 주시면 랩 일곱 장의 열쇠를 한 번에 갈아 끼워
새 스니펫으로 다시 보내드립니다. 한 줄 바꾸는 일입니다.

**유앤미 앱은 그대로 두세요.** 궁합은 계속 그쪽 이름으로 나갑니다.
두 개를 따로 두는 것이 맞습니다.

## 그때까지는

그림이 없으니 **글 본(text)** 으로 나갑니다. 깨진 그림 자리가
안 생기고 글씨가 더 크게 보입니다. 다만 이름은 아직 「유앤미」입니다.
그래서 공유 글 안에 **「스텔라 랩」**을 한 줄 넣어 두었습니다.

```
헤어지고 나서 나는 · 흔적부터 지우는 사람
눈에 안 보여야 지나간다
스텔라 랩 — 나는 어느 쪽일까
```
