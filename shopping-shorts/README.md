# 쇼핑 쇼츠 자동 제작기

소재 하나와 주제 한 줄을 넣으면 **대본 → 음성 → 자막 → 세로 영상(1080×1920 mp4)** 까지
한 번에 만들어주는, **내 컴퓨터에서 켜는** 프로그램입니다.

만든 뒤에는 컷마다 **자막과 읽는 문장을 직접 고치고**, 그 컷만 다시 구울 수 있습니다.

---

## 1. 설치 (처음 한 번만)

### ① 파이썬 설치
[python.org](https://www.python.org/downloads/) 에서 파이썬을 받아 설치하세요.
설치 화면에서 **"Add Python to PATH"** 를 꼭 체크해야 합니다.

### ② 부품 설치
이 폴더에서 명령 프롬프트를 열고:

```
pip install -r requirements.txt
```

ffmpeg는 따로 설치하지 않아도 됩니다. 위 명령이 같이 받아옵니다.

### ③ (선택) AI 대본 켜기
`ANTHROPIC_API_KEY` 를 넣어두면 대본을 AI가 씁니다. 넣지 않아도 프로그램은 돌아가고,
대신 기본 틀로 만든 초안이 나옵니다.

윈도우 명령 프롬프트:
```
setx ANTHROPIC_API_KEY "sk-ant-..."
```
(넣은 뒤 명령 프롬프트를 닫았다 다시 여세요.)

---

## 2. 켜기

윈도우는 **`run.bat` 더블클릭**, 맥·리눅스는 `./run.sh` 입니다. 직접 치려면:

```
python -m shorts web
```

브라우저가 열리면서 `http://127.0.0.1:8765` 로 들어갑니다.
**내 컴퓨터 안에서만 도는 화면입니다.** 바깥에서는 접속할 수 없습니다.

---

## 3. 쓰는 순서

### ① 새 프로젝트 만들기
| 칸 | 넣는 것 |
|---|---|
| 프로젝트 이름 | 폴더 이름이 됩니다. 예: `녹제거페인트` |
| 영상 주제 | 예: `녹 제거 및 방수 페인트` |
| 소재 | 내 컴퓨터의 **파일 경로**나 **주소**를 한 줄에 하나씩 (영상·사진 섞어도 됩니다) |
| 컷 수 | 보통 8컷 (약 15~20초) |
| 목소리 | 한국어 화자 |

**대본 만들기**를 누르면 대본과 음성까지 한 번에 만들어집니다.

### ② 대본 검수 (여기가 핵심입니다)
컷마다 이렇게 손볼 수 있습니다.

- **자막** — 화면에 박히는 글. 줄을 나눈 그대로 나옵니다
- **오디오 대본** — 실제로 읽는 문장. 자막과 다르게 써도 됩니다
- **컷 길이** — `−` `+` 로 0.1초씩
- **미리듣기** — 그 컷 음성만 들어보기
- **음성 다시** — 대본을 고친 뒤 그 컷 음성만 다시 만들기 (컷 길이도 자동으로 맞춰집니다)
- **이 컷 굽기 / 재생** — 그 컷만 영상으로 만들어 바로 확인
- **화면 소재** — 컷마다 다른 사진·영상 지정, 영상은 시작 지점(초)까지
- **효과음** — 컷에 깔 소리 파일

아래쪽 **자막 스타일**에서 폰트·크기·색·외곽선·그림자·위치와 **배경음악**을 정합니다.

### ③ 영상 만들기
**대본 확정 · 영상 만들기** 를 누르면 프로젝트 폴더에 `out.mp4` 가 나옵니다.

---

## 4. 프로젝트 폴더 구조

```
projects/녹제거페인트/
  project.json   ← 대본과 설정 (메모장으로 열어서 고쳐도 됩니다)
  media/         ← 가져온 소재
  audio/         ← 컷별 음성
  cuts/          ← 컷별 영상 (하나하나가 그대로 미리보기)
  out.mp4        ← 완성본
```

---

## 5. 명령줄로도 됩니다

```
python -m shorts new  projects/테스트 --keyword "녹 제거 페인트" --source C:\소재\상품영상.mp4
python -m shorts show  projects/테스트          # 대본 보기
python -m shorts voice projects/테스트 --scene 3 # 3번 컷 음성만 다시
python -m shorts cut   projects/테스트 --scene 3 # 3번 컷만 다시 굽기
python -m shorts render projects/테스트          # 전체 뽑기
python -m shorts voices                          # 쓸 수 있는 목소리 목록
```

---

## 6. 소재에 대해 (읽어주세요)

- **판매자·브랜드가 제휴용으로 준 소재**(쿠팡파트너스 소재함, 판매자에게 직접 받은 홍보영상,
  상세페이지 소재)는 쓰라고 만든 것이라 안전합니다.
- **남의 영상을 허락 없이 가져다 쓰는 것**은 원칙적으로 저작권 침해입니다. 판단은 사장님 몫입니다.
- 이 프로그램은 **원본 소리를 쓰지 않고 전부 TTS로 덮습니다.** 채널을 죽이는 건 대개 영상보다
  **배경음악**(Content ID)이라서, 이것만 지켜도 위험이 크게 줄어듭니다.

---

## 7. 자주 나오는 문제

| 증상 | 해결 |
|---|---|
| `ffmpeg를 찾지 못했습니다` | `pip install imageio-ffmpeg` |
| 자막이 네모(□□□)로 나옴 | 자막 스타일의 **폰트**에 컴퓨터에 있는 한글 폰트 이름을 넣으세요 (윈도우: `Malgun Gothic`) |
| 음성이 안 만들어짐 | edge-tts는 인터넷이 필요합니다. 회사 방화벽이면 막힐 수 있습니다 |
| 대본이 밋밋함 | `ANTHROPIC_API_KEY` 를 넣으면 AI가 씁니다 |
| 유튜브 주소가 안 받아짐 | `pip install yt-dlp`. 그래도 막히면 영상을 직접 받아 파일 경로로 넣으세요 |

## 8. 아직 없는 것

- 컷 사이 전환 효과, 자막 등장 애니메이션(글자효과)
- 썸네일 자동 만들기
- 유료 TTS(클로바보이스 등) 연결 — `shorts/tts.py` 의 `synthesize()` 하나만 갈아끼우면 됩니다
- AI 영상 생성(Veo 등) 소재 — `shorts/source.py` 에 갈래를 하나 더 붙이면 됩니다
